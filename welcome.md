## What is this?

PromptWaver generates immersive audiovisual experiences from text prompts. Describe a scene and a soundscape, and Claude creates the geometry, animation, and synthesized audio in realtime. 

If you don't have a Claude API account, you'll need one to create scenes, otherwise you can only play whats included.

## Quick Start

**Play scenes:**

- Click any scene in the library to load it — the **2D**/**3D** badge tells you which kind it is. 3D scenes you fly through and get camera controls; 2D scenes are flat patterns filling the frame, and get pattern controls instead
- Press the **Start** button in the header region
- Use settings under the visualiser in the left panel to control the visual output
- Change any parameters in the **Soundscape** panel to adjust audio synthisis - note theres an intentional small transisiton to soften jarring changes of values
- Use the **Scene** panel at the top of the right column to save tweaks back to the scene — **sound**, **camera** or **all**

**Generate your first scene:**

1. Click **"Generate Scene"**
2. Choose 2d or 3d scene
2. Write a visual prompt (e.g., "thousands of floating particles spiralling upward, bioluminescent colors")
3. Write an audio prompt (e.g., "ethereal pads, rising strings, subtle percussion")
4. Choose 'generative attributes' to match your scenes narrative
5. Set the ;Scene size' (3d only) - start low, scenes under 200 nodes are still very interesting, so don't think bigger is better.
5. Hit **Generate** and wait for it to be generated (10-45 seconds depending on settings)


## Performance Tips

- **MIDI** — map a hardware controller to any slider, it makes a much more enjoyable experience to build your soundscapes
- Start with **Haiku** and **small** scenes while exploring (Larger scenes take longer but look more complex)
