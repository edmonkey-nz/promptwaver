applies to the control you last learned. catch ignores a knob until it sweeps across the current value, so loading a scene never makes the first knob you touch jump the mix — the right default for voice levels. relative is for endless encoders that send deltas.
Click the small midi tag beside any slider, then move a knob. Shift-click a bound one to unmap it. Voice knobs bind to a position (voice 1, voice 2 …), not a name, so they keep working after a scene change — Pin MIDI map in the Global section ties them to one scene's actual voices instead.

Diagnostics

turns off the render-loop and audio-callback timing instrumentation live, no relaunch needed — for isolating whether the instrumentation itself costs anything. The FPS counter under the visualiser keeps working either way.

Keystone

Corrects for an off-axis-mounted laser (trapezoid distortion) — a physical rig setting, not a scene one, so it stays fixed across scene switches. Applied to the real DAC output (output/ilda.py); the visualiser above mirrors it live so you can tune by eye without the laser on.

Output monitors

Output 1 and Output 2 (header buttons) show the same live feed. Flip reverses the whole image (no reflection, unlike the Global section's "mirror"). Keystone here is independent per window — for when each screen is physically mounted/angled differently (unlike the laser's, above, these are display-only, not sent anywhere). Glow/trail/mirror (Global section) are shared between both.
Draws a small readout in the corner of each output window: its real paint rate, the cost of one paint in ms, the stroke count and the canvas size. This is the number to watch if an output looks choppy — it is not the engine's fps (under the visualiser) and not the ~20Hz state broadcast, both of which can look fine while a large full-screen canvas is too slow to keep up. Paint cost over ~25ms is highlighted; ~20fps is the ceiling by design.
